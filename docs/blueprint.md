# **App Name**: Passkey Chat

## Core Features:

- Secure Passkey Signup: Users can create an account using a unique passkey and security questions, ensuring secure access.
- Passkey Login: Users can log in using their passkey, providing a quick and secure entry to the chat interface.
- Real-time Chat: Real-time chat functionality using Supabase Realtime, enabling instant message delivery between connected users.
- Unique Invite Codes: Users can invite friends by generating a unique invite code, which, when used, connects them in the app.
- Media Sharing: Users can send text messages and share media like images and videos within the chat interface.

## Style Guidelines:

- Primary color: HSL(210, 70%, 50%) which is equivalent to a vibrant blue (#3399FF), conveying trust and security.
- Background color: A light, desaturated blue-gray (#E5E8EA), providing a calm backdrop.
- Accent color: A brighter, analogous blue (#47B7FF) will highlight interactive elements.
- Clean, modern fonts optimized for readability.
- Use simple, recognizable icons for user actions.
- Clean, minimalist layout that puts the user in focus
